# 90-second reviewer walkthrough

0–10s: Open the HTTPS link, enter the reviewer code. Mention local history and the CallMissed-only integration.

10–30s: Choose the café scenario. Ask for an offer aimed at students, in English and Hindi. Watch real text stream. Show Stop and copy controls.

30–50s: Copy an assistant reply into the canvas, refine it into an image prompt. Point out the estimate, then explicitly approve generation. Download the result.

50–75s: Start an English or Hindi voice call. Speak a short request, verify the spoken answer and transcript, demonstrate mute, then end. Calls are capped at 60 seconds and start with fresh context. Perform this part only after real audio has passed verification.

75–90s: Open session details. Distinguish provider tokens, client-observed latency and reserved allowance. Show local history clearing and explain the persistent server budget ledger. If voice is unavailable, say so and demonstrate continuing in text; never simulate a call.
